# Chapter 3: Organisation of Data

## 🗃️ Why Organise Raw Data?

Raw data collected from surveys is usually a messy heap of numbers (e.g. scores of 100 students written in random order). To make sense of it, we must **classify** it.

Economists classify data based on four key characteristics:
* **⏳ Chronological:** Classified by time (e.g., annual GDP growth from 2015 to 2025).
* **📍 Spatial:** Classified by location/geography (e.g., state-wise crop yields).
* **🎨 Qualitative:** Classified by attributes (e.g., gender, literacy status, employment category).
* **🔢 Quantitative:** Classified by measurable numerical values (e.g., height, wages, prices).

---

## 🔢 Discrete vs Continuous Variables

A variable is any characteristic whose value changes from one observation to another. Variables are classified into:

### 🧩 1. Discrete Variables
* **Features:** Increase only in complete, whole numbers (fractions are not possible).
* **Examples:** Number of children in a family (e.g., 1, 2, 3), number of cars in a parking lot.

### 🌊 2. Continuous Variables
* **Features:** Can take any numerical value, including fractions and decimals, within a range.
* **Examples:** Height of students (e.g., 5.4 ft, 5.82 ft), temperature, monthly household income.

## 🏆 Concept Check

### ❓ Quick Question:
Classify the following variable: "The exact height of 10 basketball players."

* **[A]** Discrete Variable
* **[B]** Qualitative Attribute
* **[C]** Continuous Variable
* **[D]** Chronological Series

**Correct Answer:** **C** (Continuous Variable - height can be measured in precise decimals and fractions, like 6.12 feet, unlike discrete counts).
