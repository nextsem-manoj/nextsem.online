# Phase 4: React Practical

React is a JavaScript library created by Facebook for building user interfaces. Instead of modifying the DOM manually (which is slow and messy for large apps), React lets you build reusable "Components".

---

## 1. React Basics & Components

A React application is just a tree of components. Components are basically JavaScript functions that return HTML (this syntax is called JSX).

```jsx
// A simple React Component
function Welcome() {
    return (
        <div className="card">
            <h1>Welcome to React!</h1>
            <p>This is my first component.</p>
        </div>
    );
}

export default Welcome;
```

---

## 2. Props & State

- **Props:** How we pass data *down* to components (read-only).
- **State:** How a component manages its *own* changing data over time.

```jsx
import { useState } from 'react';

function Counter({ title }) {
    // State: [currentValue, functionToUpdateValue]
    const [count, setCount] = useState(0);

    return (
        <div>
            <h2>{title}</h2> {/* Using Props */}
            <p>Current Count: {count}</p>
            <button onClick={() => setCount(count + 1)}>
                Increment
            </button>
        </div>
    );
}
```

## 3. Essential Hooks (useEffect)

`useEffect` allows you to perform side effects in your components, such as fetching data from an API when the component first loads.

```jsx
import { useState, useEffect } from 'react';

function UserList() {
    const [users, setUsers] = useState([]);

    useEffect(() => {
        // This runs once when the component mounts
        fetch("https://jsonplaceholder.typicode.com/users")
            .then(res => res.json())
            .then(data => setUsers(data));
    }, []); // Empty array means run only once

    return (
        <ul>
            {users.map(user => (
                <li key={user.id}>{user.name}</li>
            ))}
        </ul>
    );
}
```

## 4. React Router

React builds Single Page Applications (SPAs). React Router lets you navigate between different "pages" without the browser ever reloading.

```jsx
import { BrowserRouter, Routes, Route, Link } from 'react-router-dom';

function App() {
    return (
        <BrowserRouter>
            <nav>
                <Link to="/">Home</Link>
                <Link to="/about">About</Link>
            </nav>

            <Routes>
                <Route path="/" element={<Home />} />
                <Route path="/about" element={<About />} />
            </Routes>
        </BrowserRouter>
    );
}
```

## 🎓 Micro-Project: Movie Search App

Build an application that searches for movies using the OMDB API!

1. Create a `MovieCard` component that accepts movie details as Props (Title, Poster, Year).
2. Create a main `App` component with state for `searchTerm` and `movies` array.
3. Add a search input and a button.
4. When the button is clicked, use `fetch` inside React to call the OMDB API with the search term.
5. Update the `movies` state with the results, and `map()` over them to render a list of `MovieCard` components!
