# 📚 All HTML5 Tags Reference

Welcome to **P1.6: All HTML5 Tags**! Here is a comprehensive cheat sheet of all standard HTML5 tags, categorized by their primary use case. 

We've organized them into **bubbles** so you can easily scan them. Remember, you don't need to memorize all of these at once! You'll naturally learn the most important ones as you build projects.
