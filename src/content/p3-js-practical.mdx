# Phase 3: JavaScript Practical

HTML is the skeleton. CSS is the skin. JavaScript (JS) is the brain and muscle. It is the programming language of the web that enables interactive web pages.

---

## 1. JavaScript Basics

Like any programming language, JS has variables, data types, and logic.

```javascript
// Variables
let age = 20; // Can be changed
const name = "Rahul"; // Cannot be changed

// Arrays and Objects
const techStack = ["HTML", "CSS", "JS"];
const user = {
    name: "Rahul",
    role: "Developer"
};

// Conditional Logic
if (age >= 18) {
    console.log("You can access this site.");
} else {
    console.log("Too young.");
}
```

---

## 2. DOM Manipulation

The Document Object Model (DOM) is a representation of your HTML that JavaScript can read and modify.

```javascript
// Selecting an element
const heading = document.getElementById("main-heading");

// Changing text and styles
heading.innerText = "Welcome to JavaScript!";
heading.style.color = "red";
```

---

## 3. Events

JS can listen for user actions (clicks, typing, scrolling) and respond to them.

```javascript
const button = document.querySelector("#submit-btn");

button.addEventListener("click", function() {
    alert("Button was clicked!");
});
```

---

## 4. Functions & ES6+ Features

Functions allow you to write reusable blocks of code. ES6 introduced modern, cleaner syntax.

```javascript
// Traditional Function
function add(a, b) {
    return a + b;
}

// ES6 Arrow Function (Modern)
const multiply = (a, b) => a * b;

// Template Literals (String formatting)
console.log(`Hello, my name is ${user.name}`);
```

---

## 5. Local Storage

Save data directly in the user's browser so it persists even if they refresh the page.

```javascript
// Save data
localStorage.setItem("theme", "dark");

// Retrieve data
const currentTheme = localStorage.getItem("theme");
console.log(currentTheme); // "dark"
```

---

## 6. APIs & Fetch

The real power of JS comes from fetching data from external servers (APIs) asynchronously.

```javascript
// Fetching random user data
fetch("https://randomuser.me/api/")
    .then(response => response.json())
    .then(data => {
        console.log(data.results[0].name.first);
    })
    .catch(error => console.error("Error fetching data:", error));
```

## 🎓 Micro-Project: Build a To-Do List

Let's build a classic project: a To-Do App!

1. Create a simple UI with an `<input>` field, an "Add" `<button>`, and an empty `<ul>`.
2. Write JS to capture the input text when the button is clicked.
3. Create a new `<li>` element using `document.createElement()`, add the text to it, and append it to the `<ul>`.
4. (Bonus) Add a "Delete" button next to each item to remove it from the DOM.
5. (Super Bonus) Save the list to `localStorage`!
