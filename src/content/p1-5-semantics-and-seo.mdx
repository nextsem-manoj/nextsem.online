# P1.5: Semantic HTML & SEO

In the past, developers built websites using `<div>` tags for everything. While visually fine, a page full of `<div>` tags looks like meaningless soup to Google's Search Bots and Screen Readers used by visually impaired users.

Semantic HTML solves this by providing tags that describe their specific purpose.

## 1. Semantic Layout Tags

Instead of `<div id="header">`, use `<header>`.

- `<header>`: The introductory content (usually containing the logo and navigation).
- `<nav>`: The primary navigation links.
- `<main>`: The unique, primary content of the page (only one per page).
- `<article>`: A self-contained piece of content (like a blog post or news story).
- `<section>`: A thematic grouping of content (like an "About Us" or "Contact" section).
- `<aside>`: Content loosely related to the main content (like a sidebar).
- `<footer>`: The closing content (copyright, legal links).

### Example of a Semantic Layout:
```html
<body>
    <header>
        <h1>NextSem Blog</h1>
        <nav>
            <a href="/">Home</a>
            <a href="/about">About</a>
        </nav>
    </header>

    <main>
        <section id="latest-posts">
            <h2>Latest Posts</h2>
            <article>
                <h3>Why Semantics Matter</h3>
                <p>Content goes here...</p>
            </article>
        </section>

        <aside>
            <h4>About the Author</h4>
            <p>I am a frontend developer.</p>
        </aside>
    </main>

    <footer>
        <p>&copy; 2026 NextSem Academy</p>
    </footer>
</body>
```

## 2. SEO Basics (Search Engine Optimization)
SEO is how you get your website to show up on the first page of Google. Most SEO relies on the invisible `<head>` tag.

### Essential Meta Tags
```html
<head>
    <!-- Character encoding -->
    <meta charset="UTF-8">
    
    <!-- Mobile responsiveness -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    
    <!-- Title: The most important SEO factor -->
    <title>Learn Web Development | NextSem Academy</title>
    
    <!-- Description: The snippet that appears in Google search results -->
    <meta name="description" content="Master full-stack web development with our comprehensive, project-based curriculum.">
</head>
```

### Open Graph Tags (Social Media)
Have you ever pasted a link into WhatsApp or Twitter, and a beautiful preview image and title automatically appeared? That's powered by Open Graph (`og:`) meta tags.

```html
<meta property="og:title" content="Learn Web Development">
<meta property="og:description" content="Master full-stack development.">
<meta property="og:image" content="https://example.com/preview-image.jpg">
```

## 🎓 Capstone Project for P1: Semantic Personal Portfolio
This is it. The culmination of Phase 1. 

Create an `index.html` file that serves as your personal portfolio.
1. Use a strictly Semantic layout (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
2. Add a `<header>` with an `<h1>` of your name and a `<nav>` linking to internal sections (e.g., `#about`, `#skills`, `#contact`).
3. Add a section for your skills using an Unordered List `<ul>`.
4. Add a section for your Projects using a `<table border="1">` (Project Name, Tech Stack, Link).
5. Add a Contact section containing a Semantic `<form>`.
6. Include proper `<meta>` tags for SEO and a descriptive `<title>`.

Once you finish this, you have officially mastered the structure of the web. Prepare yourself for **Phase 2: CSS**, where we will take this structurally perfect portfolio and make it look visually stunning!
