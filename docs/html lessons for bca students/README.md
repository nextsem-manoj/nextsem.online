## 🎯 Educational Pedagogy Standards
1. **5-Point Concise Lesson Standard**: Every micro-lesson concept contains $\le 5$ bullet points with $\le 8$ words per sentence.
2. **Strictly Pure HTML5**: No CSS `<style>`, no inline `style=""`, and no JavaScript `<script>` tags. Pure HTML structure as tested in university practicals.
3. **🪟 Windows 11 Branding**: Standardized instructions for 🪟 Windows 11 Notepad, VS Code, and browser execution.
4. **BCA Lab Exam Ready**: Meets all requirements for lab journal submissions and university viva voce exams.
