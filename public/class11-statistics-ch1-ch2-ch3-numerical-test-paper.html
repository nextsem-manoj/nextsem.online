Q.01 [NCERT Ch 3, Page 25] 2 MARKS
The marks obtained by 15 students in a class test of Statistics are recorded as follows:
14, 22, 19, 38, 27, 45, 31, 24, 18, 41, 33, 29, 36, 42, 15
Calculate the Statistical Range (R) and determine the appropriate Class Width (h) if the data is to be grouped into exactly 6 class intervals.
सांख्यिकी की एक कक्षा परीक्षा में 15 विद्यार्थियों द्वारा प्राप्त अंक ऊपर दिए गए हैं। सांख्यिकीय परास (Range: R) की गणना कीजिए तथा यदि आंकड़ों को ठीक 6 वर्ग अंतरालों में बांटना हो, तो उपयुक्त वर्ग चौड़ाई (Class Width: h) ज्ञात कीजिए।
Working & Answer: Range = L − S = ___________; Class Size = Range / 6 = ___________
Solution & Mathematical Derivation Range R = L − S
1. Largest Value (L): 45; Smallest Value (S): 14.
2. Range (R): R = L − S = 45 − 14 = 31.
3. Class Interval Width (h): h = Range / Number of Classes = 31 / 6 ≈ 5.17 ≈ 6 (or convenient class size 5).

Q.03 [NCERT Ch 3, Page 29] 2 MARKS
The mid-points (Class Marks) of five consecutive continuous classes are given as: 12.5, 17.5, 22.5, 27.5, 32.5. Reconstruct the original Exclusive Class Limits (L1 − L2) for all 5 intervals.
पांच क्रमागत सतत वर्गों के मध्य-बिंदु (मध्य-मान) 12.5, 17.5, 22.5, 27.5, 32.5 दिए गए हैं। सभी 5 अंतरालों के लिए मूल अपवर्जी वर्ग सीमाएं (L1 − L2) पुनर्निर्मित कीजिए।
Class Size h = _________; L₁ = m − h/2; L₂ = m + h/2; Reconstructed Classes: _________________
Solution & Reconstruction Formula L₁ = m − h/2 & L₂ = m + h/2

Q.04 [NCERT Ch 3, Page 32] 2 MARKS
In a distribution of 50 workers, the frequencies for classes 0–10, 10–20, 20–30, and 30–40 are 8, 12, 20, and 10 respectively. Calculate the Relative Frequency and Percentage Frequency for the modal class (20–30).
50 श्रमिकों के वितरण में, 0-10, 10-20, 20-30, और 30-40 वर्गों की आवृत्तियां क्रमशः 8, 12, 20, और 10 हैं। बहुलक वर्ग (20-30) की आपेक्षिक आवृत्ति (Relative Frequency) और प्रतिशत आवृत्ति ज्ञात कीजिए।
Total N = 50; Relative Frequency = f / N = __________; Percentage Frequency = __________ %
Solution Rel Freq = f / N ; % Freq = (f / N) × 100
1. For modal class 20–30, Frequency f = 20; Total N = 50.
2. Relative Frequency: 20 / 50 = 0.40.
3. Percentage Frequency: 0.40 × 100 = 40%.
Q.05 [NCERT Ch 2, Page 15] 2 MARKS
A researcher wishes to select a Systematic Sample of size n = 8 from a population of N = 80 registered manufacturing firms numbered 1 to 80. Calculate the Sampling Interval (k) and state the exact firm numbers selected if the first random number selected is 6.
एक अनुसंधानकर्ता 1 से 80 तक क्रमांकित N = 80 पंजीकृत विनिर्माण फर्मों की समष्टि से n = 8 आकार का क्रमबद्ध प्रतिदर्श (Systematic Sample) चुनना चाहता है। प्रतिचयन अंतराल (k) ज्ञात कीजिए और यदि पहला यादृच्छिक अंक 6 चुना गया है, तो चयनित फर्मों के सही क्रमांक लिखिए।
Sampling Interval k = N / n = ________; Selected Firm Numbers: __________________________________
Solution k = N / n = 80 / 8 = 10
1. Sampling interval k = N / n = 80 / 8 = 10.
2. With random start = 6, subsequent units are 6 + 10, 6 + 20, 6 + 30, …
3. Selected sample firms: 6, 16, 26, 36, 46, 56, 66, 76.
Q.06 [NCERT Ch 2, Page 17] 2 MARKS
In an agricultural survey, questionnaires were mailed to 500 wheat farmers. If 420 questionnaires were returned with complete valid responses and 80 were unreturned or incomplete, compute: (a) Response Rate (%), and (b) Non-Response Error Percentage (%).
एक कृषि सर्वेक्षण में 500 गेहूं किसानों को डाक द्वारा प्रश्नावली भेजी गई। यदि 420 प्रश्नावली पूर्ण एवं वैध उत्तरों के साथ वापस आईं और 80 वापस नहीं आईं, तो गणना कीजिए: (क) प्रतिसाद दर (Response Rate %), और (ख) अप्रतिसाद त्रुटि प्रतिशत (Non-Response Rate %)।
(a) Response Rate = (420 / 500) × 100 = _________ %; (b) Non-Response Rate = _________ %
Solution Rate = (Count / Total) × 100
1. Response Rate: (420 / 500) × 100 = 84%.
2. Non-Response Error Rate: (80 / 500) × 100 = 16%.
