assignment Exercise 1.1 • Question 2 High-Yield NCERT

Show that the relation R in the set ℝ of real numbers, defined as:

R = { (a, b) : a ≤ b² }

is neither reflexive, nor symmetric, nor transitive.

verified Verified Problem Formulation Mark Allocation: 4M
insights Geometric Intuition

Real interval (0, 1) inverts standard quadratic ordering: squaring a fraction shrinks its magnitude, providing immediate counter-examples.

Rigorous Stepwise Derivation
task_alt Step-by-Step
1

Testing Reflexivity

Fails (a ≤ a²)

∀ a ∈ ℝ, (a, a) ∈ R ⇔ a ≤ a²

lightbulb Counter-Example (Fractional Domain):

Let a = ½ ∈ ℝ.
Then a² = (½)² = ¼.
Since ½ > ¼ (i.e. ½ ≰ (½)²), it implies:

(½, ½) ∉ R → Non-reflexive confirmed
2

Testing Symmetry

Fails ((a, b) ⇏ (b, a))

(a, b) ∈ R ⇒ (b, a) ∈ R

sync_problem Asymmetry Demonstration:

Choose a = 1 and b = 4.
Here 1 ≤ 4² = 16 is true, thus (1, 4) ∈ R.
However, evaluate the converse:

4 ≰ 1²  (4 > 1)  ⇒  (4, 1) ∉ R
Hence, the relation R is strictly not symmetric.
3

Testing Transitivity

Fails Chain Condition

(a, b) ∈ R ∧ (b, c) ∈ R ⇒ (a, c) ∈ R

crisis_alert Negative Real Triplet Counter-Example:

Let a = 3, b = -2, and c = -1.

1. 3 ≤ (-2)² = 4  → (3, -2) ∈ R
2. -2 ≤ (-1)² = 1  → (-2, -1) ∈ R
3. But 3 ≰ (-1)² = 1  → (3, -1) ∉ R

The link collapses at the terminal pair: (3, -1) ∉ R.

verified
Q.E.D. Hence Proved 100% Academic Accuracy

The relation R is neither reflexive, nor symmetric, nor transitive in ℝ.

Bijective Function Axiom

Theorem 1.2 Definition

f: A → B is bijective ⇔ (f is injective ∧ f is surjective)

Every element in set B has a unique pre-image in set A.
